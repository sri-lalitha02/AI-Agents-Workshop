# Day 01 - One Person Company: AI Agents Workshop

## Overview
This Task is part of the 12-day One Person Company – AI Agents Workshop conducted by the Department of Technical Training (DoTT), Aditya University.

## Objective
To explore Large Language Models (LLMs), integrate the Groq API, and understand prompt safety using Prompt Guard.

## Technologies Used
- Python
- Google Colab
- Groq API
- LangChain

## Implementation
- Integrated Groq API using LangChain.
- Developed a Sweet Crumbs Home Bakery Chatbot.
- Developed a Healthcare Assistant Chatbot.
- Used Prompt Guard to explore unsafe prompt detection.
- Explored Prompt Guard for unsafe prompt detection.
- Tested LLM responses using Groq models.
